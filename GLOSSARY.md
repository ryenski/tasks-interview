# Tasks

A shared to-do list that logged-in users work through together.

## Language

**Task**:
A unit of work with a required title and an optional description, visible to every user.
_Avoid_: Todo, item

**Complete**:
The state of a Task whose work is finished.
_Avoid_: Done, closed, finished

**Incomplete**:
The state of a Task whose work is not yet finished; every Task starts here.
_Avoid_: Open, pending, uncompleted

**Mark complete / Mark incomplete**:
Moving a Task between the Complete and Incomplete states.
_Avoid_: Close, reopen, check off, un-complete
